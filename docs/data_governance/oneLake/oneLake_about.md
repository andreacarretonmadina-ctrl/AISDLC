**What is OneLake?**

OneLake on AWS Data Lake is a storage system or repository that collects and stores large amounts of data in its original, raw form. The term "data lake" refers to the image of a natural reservoir into which various information streams flow - similarly, a Data Lake can store data from various sources and in various formats.

OneLake provides also Data Governance capabilities tightly coupled with RDM (Roche Data Marketplace). 

**When you need the OneLake?**

If you work with large amounts of unstructured data, such as text files, logs, images, videos or data from IoT devices, Data Lake will be the right choice. Data Lake stores data in its original form, which allows it to be transformed later as needed.

Data Lake is ideal for data mining, big data analysis, and advanced analytics such as machine learning, predictive modeling, and correlation research. This is a good solution if you want to test and explore different datasets without structuring them first. 

**Why should you choose OneLake?**

Choosing OneLake offers scalable, unified storage for diverse data types, making it ideal for advanced analytics and machine learning. It provides flexibility, cost efficiency, robust security, and seamless integration with existing tools for effective data management and analysis.
