Configuration and Logging
=========================

* * * * *

In case there is used DVA tool, following tables should be usually created in raw dv schema as well.  

#### 1\. CONFIG_DATA_TYPES [](https://data-engineering-docs-52075d.pages.roche.com/docs/data-modeling/data-vault/raw-dv-layer/rdv-configuration-and-logging/#1-config_)

Table used by DVA tool to map source column types to snowflake column types

| Column Name | Type | Column Description |
| --- | --- | --- |
| `CONFIG_TYPE` | VARCHAR | Data type from the source |
| `SNOWFLAKE_TYPE` | VARCHAR | Equivalent of the source data type in Snowflake |

👉

View Table DDL

```
```sql
create or replace TABLE DEV_DIA.RAW_DV_QUALITY_AND_REGULATORY.CONFIG_DATA_TYPES (
    CONFIG_TYPE VARCHAR(16777216),
    SNOWFLAKE_TYPE VARCHAR(16777216)
);
```

```

#### 2\. CONFIG_RAW_DV_LOAD_STATUS [](https://data-engineering-docs-52075d.pages.roche.com/docs/data-modeling/data-vault/raw-dv-layer/rdv-configuration-and-logging/#2-config_)

Table storing information about loaded data to RAW DV , utilized by by python launcher of procedures generated by DVA tool.

| Column Name | Type | Column Description |
| --- | --- | --- |
| `SYS_LOADED_ID` | ARRAY |  |
| `OBJECT` | VARCHAR |  |
| `PSA_SOURCE` | VARCHAR |  |
| `LOAD_COMPLETION_DATE` | TIMESTAMP_LTZ |  |
| `PIPELINE_NAME` | VARCHAR |  |
| `PIPELINE_ID` | VARCHAR |  |

👉

View Table DDL

```
```sql
create or replace TABLE <DATABASE>.RAW_DV_<DOMAIN>.CONFIG_RAW_DV_LOAD_STATUS (
    SYS_LOADED_ID ARRAY,
    OBJECT VARCHAR(16777216),
    PSA_SOURCE VARCHAR(16777216),
    LOAD_COMPLETION_DATE TIMESTAMP_LTZ(9),
    PIPELINE_NAME VARCHAR(16777216),
    PIPELINE_ID VARCHAR(16777216)
);
```

```

#### 3\. CONFIG_PROCEDURE_STATUS [](https://data-engineering-docs-52075d.pages.roche.com/docs/data-modeling/data-vault/raw-dv-layer/rdv-configuration-and-logging/#3-config_)

Table storing logs of procedures generated by data vault automation tool. Needed only if procedure generated by DVA are used to populate objects in the layer.

| Column Name | Type | Column Description |
| --- | --- | --- |
| `PROCEDURE_NAME` | VARCHAR |  |
| `UPDATE_NEEDED` | BOOLEAN |  |
| `SYS_LOADED_ID` | NUMBER |  |
| `PROCEDURE` | VARCHAR |  |
| `ERROR_LOG` | VARIANT |  |
| `SYS_CREATED` | TIMESTAMP_NTZ |  |

👉

View Table DDL

```
```sql
create or replace TABLE <DATABASE>.RAW_DV_<DOMAIN>.CONFIG_PROCEDURE_STATUS (
    PROCEDURE_NAME VARCHAR(16777216) DEFAULT PROCEDURE,
    UPDATE_NEEDED BOOLEAN,
    SYS_LOADED_ID NUMBER(38,0),
    PROCEDURE VARCHAR(16777216),
    ERROR_LOG VARIANT,
    SYS_CREATED TIMESTAMP_NTZ(9) DEFAULT CURRENT_TIMESTAMP()
);
```
