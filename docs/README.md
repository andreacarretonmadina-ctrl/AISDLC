# Documentation

This folder contains technical documentation organized by domain.

## Structure

### [`adobe-analytics/`](./adobe-analytics/)

Documentation related to Adobe Analytics integration.

### [`agent/`](./agent/)

Guidelines and references for AI/agent development.

- `glossary.md` – Key terms and definitions.
- `golden-rules.md` – Core principles and rules to follow.

### [`data warehousing/`](./data%20warehousing/)

Documentation for data warehousing platforms.

- **Snowflake** – Account creation, data governance, ingestion architecture, security, and technical standards.

### [`data_governance/`](./data_governance/)

Data governance strategy and architecture.

- **oneLake** – Overview and product documentation for OneLake.
- **oneLake-for-awsGlue** – Integration of OneLake with AWS Glue (catalogs, Iceberg tables, architecture).
- **oneLake-for-awsS3** – Integration of OneLake with AWS S3 (governed data lake, user roles).

### [`data_modeling/`](./data_modeling/)

Data modeling standards and layer definitions.

- `business-layer.md` – Business layer design.
- `configuration-and-logging.md` – Configuration and logging standards.
- `data_vault.md` – Data Vault methodology.
- `data-load-approach.md` – Data load strategies.
- `data-product-layer.md` – Data product layer design.
- `raw-data-vault-layer.md` – Raw Data Vault layer specification.

### [`samples/`](./samples/)

Code or configuration samples supporting the documentation.
