# Maelle – How to Track Events

This folder contains documentation and event samples for tracking user interactions on the Maelle website using the Event-Driven Data Layer (EDDL).

## Contents

- [eddl-overview.md](./eddl-overview.md) – Overview of the EDDL concept and how to push events.
- [`../maelle-tracking-events/`](../maelle-tracking-events/) – JSON samples for each tracked event, organized by event type.

## Event types

| Folder | Description |
|--------|-------------|
| `defaultLinkClick events` | Tracks user clicks on links and buttons |
| `defaultPageView events` | Tracks page view events |
| `onSiteSearch events` | Tracks search queries |
| `onSiteSearchClick events` | Tracks clicks on search results |
